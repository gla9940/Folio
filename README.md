# Folio

React + TypeScript + Vite로 만든 개인용 EPUB/TXT 리더입니다. 파일은 브라우저에서 분석하여 IndexedDB에 저장합니다. 로그인, API 키, 서버 환경변수, 외부 저장 서비스가 필요하지 않습니다.

## 실행과 배포

```sh
npm ci
npm run dev
npm run build
npm run preview
npm test
npm run test:e2e
```

Node.js 22.12 이상 권장. Vercel에서 Framework Preset **Vite**, Build Command **npm run build**, Output Directory **dist**로 배포합니다. 서버리스 함수와 별도 환경변수는 없습니다. 브라우저 테스트는 설치된 Google Chrome을 기본으로 사용하며, 다른 설치 환경은 `PLAYWRIGHT_CHANNEL`로 지정합니다.

## 서재와 독서

- 목차의 **파일 등록 · 7장 목차**에서 EPUB/TXT 파일을 선택하고 추출된 목차를 확인한 뒤 등록합니다. 여러 화는 한 권으로 묶입니다.
- EPUB 2 NCX / EPUB 3 navigation, OPF spine 순서, 같은 XHTML 안의 목차 앵커를 분석합니다. 본문은 텍스트로 추출하여 문단·대사 줄바꿈을 유지하고 스크립트·이미지·외부 리소스를 실행하지 않습니다. DRM 파일은 지원하지 않습니다.
- TXT는 UTF-8, UTF-16 LE/BE, EUC-KR을 지원합니다. `Chapter N`, `Arc N, Chapter N`, `제N화`, `제N장` 제목으로 나누며 제목이 없으면 한 화로 등록합니다. 빈 줄로 문단을 구분합니다.
- 파일 최대 20MB, EPUB 압축 해제 예상 크기 80MB·문서당 4MB·3,000개 파일, 전체 500화·1,000만 자 제한입니다. 화별 15만 자·2,500문단·문단별 6,000자 제한을 넘으면 파일 분할을 안내합니다.
- WCT 7장 116개 항목의 제목·번호·원본 새 탭 링크·검색을 유지합니다. 본문 자동 가져오기는 제공하지 않습니다. 이미 저장된 URL 원문도 계속 읽을 수 있습니다.
- PC는 좌측 목차·중앙 본문·우측 설정, 모바일은 본문과 접이식 메뉴를 표시합니다. 세피아/라이트/다크, 글자 크기·줄 간격·본문 너비를 조절할 수 있습니다.
- 세로 스크롤과 가로 페이지를 지원합니다. PC 방향키/버튼, 모바일 좌우 터치/스와이프로 페이지를 이동합니다. Safe Area와 Visual Viewport 높이 변화를 반영합니다.
- 읽던 화·문단 위치·북마크·설정은 기존 localStorage 키로 저장합니다. 목차의 읽음 표시는 진행률 98% 이상에서 기록합니다.

## 서재 관리

목차의 **서재 관리 → 내 서재**에서 등록한 책을 검색하고 최근 읽은 순·제목순·등록순(최신 먼저)으로 정렬합니다. **이어서 읽기**로 마지막에 읽던 책과 저장한 문단을 다시 엽니다. 책별 진행률은 화별 원문 길이를 가중하여 계산하고, 예전 기록은 저장된 문단·문자 위치에서 계산합니다.

책 옆 **···**에서 제목을 수정하거나 삭제할 수 있습니다. 수정한 제목은 원문과 분리된 설정에 저장하므로 문단 ID·목차·북마크·읽던 위치가 유지되고 동일 파일을 재등록해도 제목이 유지됩니다. 삭제 확인 화면에서 확정하면 해당 책의 모든 화, 연결된 이전 캐시·설정, 북마크와 독서 기록만 제거합니다. 다른 책과 공통 설정은 유지합니다. 현재 책 삭제 시 샘플로 돌아가 다른 책의 마지막 읽은 시간이 바뀌지 않게 합니다. 기본 샘플은 수정·삭제 대상에서 제외됩니다.

## 기존 데이터 보존

IndexedDB 이름 `folio-library-v1`, 버전 **1**, 기존 store와 레코드 형식 및 문단 ID 생성 방식을 유지합니다. 자동 삭제·초기화·마이그레이션을 수행하지 않습니다. 이전 버전의 사용하지 않는 저장소와 언어 설정도 보존하며, 사용자가 책 삭제를 확정할 때만 해당 책에 연결된 항목을 정리합니다. 이미 등록한 파일을 다시 업로드할 필요가 없습니다.

동일한 파일 바이트를 재등록하면 기존 ID를 유지합니다. 파일 내용이 바뀌면 새 책으로 취급합니다. 저장 데이터는 브라우저·기기·접속 주소별로 분리되므로 기존 배포 주소에서 계속 사용하세요.

## Chrome 기본 웹페이지 번역

영어 본문을 연 상태에서 [Chrome 공식 안내](https://support.google.com/chrome/answer/173424?hl=ko)에 따라 PC 주소창 번역 아이콘/우클릭 메뉴 또는 Android Chrome 메뉴의 **번역**을 사용하세요. 번역 가능 여부·자동 번역·결과는 브라우저 설정과 서비스 상태에 달려 있습니다. Folio는 브라우저 번역을 직접 실행하거나 강제하지 않습니다.

- 본문 언어를 문서 언어에 반영하고 한국어 조작 UI에는 `lang=ko`, `translate=no`를 지정합니다.
- 본문과 화 제목은 React가 내부 텍스트 노드를 갱신하지 않는 안정적인 span 경계에 렌더링합니다. 브라우저가 내부 노드를 교체해도 북마크·설정·페이지 이동 시 원문으로 덮어쓰거나 해당 텍스트 노드를 삭제하지 않습니다.
- 본문의 노드·문자·서식 변경을 MutationObserver로 감지하여 가로 페이지를 다시 조판합니다. 숨겨진 원문 텍스트 노드를 측정에서 제외하고, 원문 길이에 대한 상대 문자 위치를 이용해 같은 문단을 유지합니다.
- 모드 전환·화 이동·새로고침은 원문 DOM을 새로 표시할 수 있습니다. 브라우저가 새 본문을 번역하지 않으면 Chrome 메뉴에서 번역을 다시 선택하세요. 브라우저 번역문을 원문 데이터에 덮어쓰지 않습니다.
- 임의 확장 프로그램이 본문 경계 요소 자체를 삭제하는 경우까지 보장하지 않습니다.

## 검증과 구조

`tests/reader.spec.ts`, `pagination.spec.ts`의 기존 독서 테스트를 유지하고 파일 등록·저장 호환성·번역 DOM 변경 테스트를 실행합니다. 자동 테스트는 설치된 Chrome의 PC/모바일 터치 에뮬레이션에서 텍스트 노드 교체·font 래핑·숨긴 원문·긴 한국어 문장을 재현합니다. Chrome 실제 번역 메뉴나 Android 실기기 번역 서비스의 성공을 자동 테스트로 간주하지 않습니다.

자세한 결과는 [검증 기록](docs/integration-verification.md)을 참고하세요.

```text
src/components/ReaderText.tsx       # 브라우저가 내부 텍스트 DOM을 변경할 수 있는 경계
src/components/PaginatedChapter.tsx # 조판·MutationObserver·페이지 이동
src/hooks/useReader.ts              # 기존 위치·북마크·설정 저장
src/hooks/useNovelLibrary.ts        # 기기 서재·책별 목차·읽음 상태
src/services/fileImport.ts          # 클라이언트 EPUB/TXT 파서
src/services/novelCache.ts          # 변경 없는 IndexedDB v1
src/domain/readingPosition.ts      # 보이는 텍스트와 원문 기준 문자 위치 매핑
shared/novels.ts                    # 기존 원문 모델·안정적인 ID
```
